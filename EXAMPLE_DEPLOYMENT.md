## Troubleshooting Common Issues

### Issue: "Post cooldown active"

**Solution:**
```bash
# Check which account is ready
python3 example_moltbook_usage.py accounts

# Use another account
export MOLTBOOK_API_KEY="$MOLTBOOK_API_KEY_2"
python3 example_moltbook_usage.py deploy
```

### Issue: "Bankr didn't detect my tweet"

**Solution:**
1. Verify tweet format exactly matches:
   ```
   @bankr deploy this token with the ticker $TICKER. Send the fees to @handle.
   ```
2. Ensure your Twitter account is verified
3. Check Bankr bot is online (@bankr on Twitter)
4. Wait 1-2 minutes and try again

### Issue: "No trending topics found"

**Solution:**
- Script will use default memecoin patterns
- Manually input ticker name when prompted
- Try Option 3 first to see available trends
- Check your MoltBook connection

## Advanced: Programmatic Deployment

### Python Script Example

```python
#!/usr/bin/env python3
"""
Automated multi-account deployment script
"""

from moltbook_standalone import MoltbookClient
from example_moltbook_usage import _generate_viral_ticker, _analyze_crypto_trends
import time
import os

# Load all accounts
accounts = [
    {"name": "Account1", "api_key": os.getenv("MOLTBOOK_API_KEY_1")},
    {"name": "Account2", "api_key": os.getenv("MOLTBOOK_API_KEY_2")},
    {"name": "Account3", "api_key": os.getenv("MOLTBOOK_API_KEY_3")},
]

twitter_handle = "@mycrypto_agent"

for i, account in enumerate(accounts):
    print(f"\n{'='*60}")
    print(f"Deploying token for {account['name']}")
    print(f"{'='*60}")
    
    # Initialize client
    client = MoltbookClient(api_key=account['api_key'])
    
    # Analyze trends
    trends = _analyze_crypto_trends(client)
    ticker = _generate_viral_ticker([trends[0]['topic']] if trends else [])
    
    # Create proposal
    proposal = client.propose_meme_token(
        ticker=ticker,
        name=f"{ticker} Token",
        description=f"Automated deployment for {account['name']}"
    )
    
    # Generate Bankr tweet
    bankr_tweet = client.deploy_token_via_bankr(ticker, twitter_handle)
    
    print(f"\n✅ Ready to deploy ${ticker}")
    print(f"📢 Tweet: {bankr_tweet}")
    
    # Wait 6 minutes before next deployment (stagger timing)
    if i < len(accounts) - 1:
        print(f"\n⏳ Waiting 6 minutes before next deployment...")
        time.sleep(360)

print("\n✅ All deployments complete!")
```
