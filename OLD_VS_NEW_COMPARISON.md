## 🛡️ Reliability Comparison

### Error Handling

**Old Script:**
```python
def _safe_request(self, method, endpoint, payload=None, retries=5):
    for attempt in range(retries):
        response = requests.post(...)
        if response.status_code == 200:
            return response.json()
        if response.status_code in [500, 502, 503]:
            time.sleep(5)  # Fixed 5s wait
            continue
```

**Problem:** 
- Fixed wait time (not optimal)
- No timeout protection
- Limited error logging

---

**New Engine:**
```python
def _safe_request(self, method, endpoint, payload=None, retries=5):
    for attempt in range(retries):
        try:
            response = requests.post(..., timeout=30)  # Timeout protection
            
            if response.status_code in [200, 201]:
                logger.info(f"✅ Success (Status: {response.status_code})")
                return response.json()
            
            if response.status_code in [429, 500, 502, 503, 504]:
                wait_time = 5 * (attempt + 1)  # Exponential backoff
                logger.warning(f"⚠️ Server error. Retry {attempt}/{retries} in {wait_time}s")
                time.sleep(wait_time)
                continue
        
        except requests.exceptions.Timeout:
            logger.warning(f"⏱️ Timeout. Retry {attempt}/{retries}")
            continue
```

**Advantages:**
- Exponential backoff (5s, 10s, 15s, 20s, 25s)
- Timeout protection (30s)
- Detailed logging for debugging
- Handles rate limits (429)
- Exception safety
